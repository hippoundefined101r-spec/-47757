# MEBEL FLOW V1

Рабочая первая версия системы продаж для мебели на заказ.

## Что работает
- Публичный сайт и форма расчёта.
- Загрузка фотографий помещения.
- Заявки сохраняются в БД.
- Мини-CRM со статусами сделки и напоминанием о дожиме.
- Контент-панель: одна работа → тексты Telegram / VK / Instagram.
- Работы из контент-панели появляются в портфолио сайта.
- Telegram-уведомления о новых заявках и публикация текста в Telegram-канал после подключения токена.
- Фото хранятся в БД, поэтому не пропадают при перезапуске web-сервиса.

## Render
В репозитории есть `render.yaml`: он создаёт бесплатный Python web service и бесплатную Render PostgreSQL базу в Frankfurt.

При первом развёртывании Render попросит `ADMIN_PASSWORD`. Telegram-переменные можно пока оставить пустыми и добавить позже.

> Важно: бесплатная Render PostgreSQL база в текущем тарифе истекает через 30 дней. Этот вариант подходит для первого запуска и проверки с реальными лидами. Перед постоянной эксплуатацией переносим БД на постоянное хранилище или платный тариф.

## Локальный запуск
Без `DATABASE_URL` приложение использует SQLite:

```bash
python app.py
```
